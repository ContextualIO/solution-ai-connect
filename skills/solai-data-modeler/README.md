# solai-data-modeler

Portable skill for designing and validating Contextual.io Object Type schemas.

This repository is designed to work in two ways:

- installed directly as a standalone skill in a coding agent
- included as a submodule inside a Claude plugin or similar bundle at `skills/solai-data-modeler/`

Pairs with `solai-cli` for deployment and `solai-knowledge` for doc-backed schema verification.
